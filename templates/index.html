Load Data

The dataset for Composite vector search is Customer Care Emails dataset, a synthetic dataset that includes sender, receive, and message body.

The dataset for Hyperscale vector search is Wikipedia Movie Plots dataset, which includes movie plot and title text fields.

The dataset for Hybrid vector search is Businesses from the Yelp Dataset, which includes business name and categories (text) and latitude/longitude (floating point numbers).

Instead of loading and vectorizing data yourself, you can use AI Services to vectorize data and store data during loading and updating, automatically, using a private hosted model or external model. See the AI Services documentation for more details.
